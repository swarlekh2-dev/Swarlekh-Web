SwarLekh website
================
Files
  index.html   - all pages (Home, Product, Technology, About, Contact)
  style.css    - white and blue theme, animations, stickers
  script.js    - page navigation, theme toggle, forms, hero animation
  images/      - put founder.jpg here (your photo)

How to run
  Double-click index.html, or host the whole folder on Netlify, GitHub Pages or Vercel.

Contact forms
  Forms send to swarlekh2@gmail.com through FormSubmit (formsubmit.co).
  After you host the site, submit the form once yourself, then open the
  activation email from FormSubmit and confirm. After that every message arrives in your inbox.
  If sending fails, the form opens the visitor's email app as a backup.
