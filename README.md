SwarLekh
========
An AI-powered examination platform for colleges and universities.

WHAT IT DOES
- Creates question papers
- Delivers exams online
- Manages student answers
- Helps with evaluation and result processing

WHY IT MATTERS
Visually impaired students often struggle to find a scribe for exams.
SwarLekh supports screen readers, text-to-speech and voice answers,
so they can write exams independently.

TECHNOLOGY
AI, Machine Learning, Lemma (lemma.work), Speech technology, NLP
